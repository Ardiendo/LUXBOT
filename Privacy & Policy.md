# Privacy & Policy

**Lux** Discord Bot Privacy Policy

**Last Updated:** November 26, 2025

## 1. Introduction

Welcome to **Lux** ("Bot," "we," "us," "our"). We are committed to protecting your privacy and ensuring transparency about how we collect, use, and process your data. This Privacy Policy explains our practices regarding data collection and use when you interact with Lux on Discord.

By using Lux, you acknowledge that you have read, understood, and agree to the terms of this Privacy Policy. If you do not agree with our practices, please discontinue using the Bot.

## 2. Data We Collect

### 2.1 Discord User Information
When you interact with Lux, we may collect and process:
- **User ID** - Your unique Discord identifier
- **Username and Discriminator** - Your Discord display name
- **Server/Guild ID** - The Discord server where interactions occur
- **Role IDs** - For role reward assignment functionality
- **Message Content** - Only when explicitly required by commands (e.g., purge, moderation)

### 2.2 Activity Data
- **Level and XP Data** - Retrieved from Mee6's public API
- **Ticket Information** - Ticket creation, claims, and closure data
- **Economy Data** - User balances, purchased items, and transactions
- **Command Usage** - Commands executed and their parameters
- **Interaction Logs** - Timestamps and types of Bot interactions

### 2.3 Configuration Data
- **Server Settings** - Role rewards, log channels, notifications configuration
- **Custom Rules** - Server rules customization and preferences
- **Bot Preferences** - Per-guild feature toggles and settings

## 3. How We Use Your Data

### 3.1 Primary Uses
We use collected data to:
- Assign and manage role rewards based on Mee6 levels
- Manage the economy system (balances, shop transactions)
- Support ticket creation and management
- Execute commands and provide Bot functionality
- Maintain server-specific configurations
- Display user statistics and information

### 3.2 Secondary Uses
We use data to:
- Debug issues and troubleshoot Bot problems
- Improve Bot performance and user experience
- Track command usage for feature optimization
- Detect and prevent abuse or misuse
- Comply with Discord's Terms of Service

### 3.3 Data NOT Shared
We do **NOT**:
- Share your data with third parties (except as required by law)
- Sell or monetize your personal information
- Share data with advertisers or marketing services
- Store your data for purposes beyond Bot functionality
- Track personal information across Discord servers

## 4. Data Storage

### 4.1 Storage Location
Your data is stored in:
- **JSON configuration files** - Local storage on the Bot's hosting environment
- **PostgreSQL Database** (optional) - If database integration is enabled by server administrators

### 4.2 Data Retention
- **Configuration Data** - Retained indefinitely until deleted by server administrators
- **Activity Data** - Retained for operational purposes; specific retention periods vary
- **Economy Data** - Retained indefinitely for balances and transaction history
- **Ticket Data** - Retained indefinitely for reference and statistics

### 4.3 Data Deletion
Users and administrators can request data deletion by:
1. Using `/backup` command to export your data
2. Contacting the Bot developer (_.aari._)
3. Requesting data removal through Discord direct messages

## 5. Discord Integration

### 5.1 Discord API Usage
Lux uses Discord's official API to:
- Fetch user information and server configurations
- Manage roles and permissions
- Create and manage tickets
- Log events and errors

### 5.2 Discord Data Policy Compliance
We comply with Discord's Data Processing Addendum and maintain alignment with Discord's privacy standards.

## 6. Security Measures

### 6.1 Data Protection
We implement:
- Environment variable encryption for sensitive tokens
- No logging of sensitive information (tokens, passwords)
- Role-based permission checks
- Error handling that doesn't expose sensitive data
- Database query sanitization (if using PostgreSQL)

### 6.2 Limitations
While we implement security measures, **no security system is perfect**. We cannot guarantee absolute security of your data. Use the Bot at your own risk.

## 7. Third-Party Services

### 7.1 Mee6 Public API
Lux retrieves user level data from Mee6's public API:
- **Data Retrieved** - User levels and leaderboard information
- **No Authentication Required** - The API is public and requires no credentials
- **Mee6 Privacy Policy** - Mee6 independently maintains user data; review their privacy policy

### 7.2 Discord's Services
As a Discord Bot, we are subject to:
- Discord's Terms of Service
- Discord's Privacy Policy
- Discord's Data Processing Terms

## 8. User Rights

### 8.1 Access Your Data
You have the right to request access to the data we hold about you. Contact the Bot developer to exercise this right.

### 8.2 Delete Your Data
You have the right to request deletion of your data, subject to legal and technical limitations.

### 8.3 Data Portability
You can request an export of your data in a portable format via the `/backup` command.

## 9. Age Restriction

Lux is not intended for users under **13 years of age** (or the minimum age required in your jurisdiction). If you are under 13, do not use Lux. We do not knowingly collect information from users under 13.

We may update this Privacy Policy at any time without prior notice. Your continued use of Lux after changes constitutes acceptance of the updated policy. We recommend reviewing this policy periodically.
